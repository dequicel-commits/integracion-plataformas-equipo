# MATRIZ DE TRAZABILIDAD DE REQUISITOS – ENTREGA 3

## Proyecto: Peluditos Pet Chile

**Rol:** Analista de Procesos / Elvis Gutiérrez 

### 1. Objetivo

La presente matriz tiene como objetivo relacionar los requisitos funcionales del proyecto Peluditos Pet Chile con los componentes tecnológicos responsables de su implementación y los casos de prueba definidos para verificar su funcionamiento.

Este documento permitirá realizar un seguimiento del cumplimiento de los requisitos durante la tercera entrega.

### 3. Estados de validación

Los estados utilizados para el seguimiento serán:

- **Aprobado:** el requisito fue comprobado mediante pruebas y evidencias.
- **Rechazado:** el requisito fue probado, pero no cumplió el resultado esperado.
- **Pendiente de validar:** todavía no existe evidencia suficiente para confirmar su cumplimiento.

### 4. Seguimiento de requisitos

Durante la tercera entrega, cada requisito deberá verificarse mediante los casos de prueba correspondientes.

Las evidencias podrán incluir capturas de pantalla, respuestas de servicios REST, registros de ejecución de Flowable y resultados de consultas a la base de datos.

El estado de cada requisito se actualizará una vez que el equipo confirme su funcionamiento.

### 5. Conclusión

La matriz de trazabilidad permite mantener un control organizado de los requisitos funcionales del proyecto y relacionarlos con las actividades de implementación y pruebas.

Desde el rol de Analista de Procesos, este documento contribuye a identificar requisitos pendientes, facilitar la coordinación con los demás integrantes y comprobar el avance hacia una solución integrada y funcional para Peluditos Pet Chile.
