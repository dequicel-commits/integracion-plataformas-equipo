# Evidencias QA - Entrega 3

En esta carpeta se encuentran las capturas de las pruebas realizadas durante la Entrega 3 de Peluditos Pet Chile.

Se incluyen pruebas de los servicios Jakarta REST, Flowable OSS, External Workers, persistencia de datos, validaciones y funcionamiento de la interfaz web.

También se documentan los resultados obtenidos, los errores encontrados y las limitaciones conocidas.
