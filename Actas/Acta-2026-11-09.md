## 1. Objetivo

Coordinar y revisar los avances de la segunda entrega del proyecto Peluditos Pet Chile, considerando la actualización del proceso BPMN, el desarrollo de la base de datos, la implementación e integración de los componentes, las pruebas de funcionamiento y la preparación de los videos.

## 2. Actividades realizadas

### 6 de noviembre

El equipo conversó sobre la posibilidad de incorporar las campañas, cumpleaños de mascotas y fechas especiales solicitadas por la emprendedora. Se acordó incluirlas en el modelo BPMN, dejando su implementación para la tercera entrega.

Geraldine actualizó el modelo TO-BE, incorporando una tarea automática para guardar los datos del potencial cliente y un proceso separado para las campañas. El modelo fue validado en Flowable Design sin presentar errores. También subió a GitHub el análisis de requisitos actualizado.

Además, agregó el campo de autorización para recibir información promocional y compartió el diagrama entidad-relación.

Se definieron los servicios REST necesarios para registrar y consultar clientes, junto con la integración del External Worker con Flowable.

Elvis, encargado de las pruebas QA/Tester, solicitó apoyo a Lautaro para conocer los pasos necesarios para realizar las pruebas de funcionamiento una vez que estuviera disponible el código.
